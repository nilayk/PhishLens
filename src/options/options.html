PhishLens

Explainable phishing and social-engineering analysis for Gmail. Advisory only — PhishLens never blocks links, downloads, or replies.

AI analysis

Technical checks — sender domains, links, attachments, wording patterns — always run on this device and need no AI. This setting only controls the optional semantic layer.

Must be https://. PhishLens only ever talks to this backend, never directly to a model vendor, and carries no API key.

Permissions

Every permission in the manifest, and why it is there.

Permission Why
host_permissions: https://mail.google.com/* Read the open message from the page in order to analyse it. This is the only site PhishLens can run on.
storage Persist the settings on this page. No message content is ever stored.

Not requested: activeTab, <all_urls>, scripting, webRequest, tabs, or downloads.

Privacy

Message content is read into memory, analysed, and discarded. Bodies are never written to storage or logged in a release build. Results are cached in the tab only for as long as the tab is open. With AI off or on-device, nothing derived from a message leaves the browser.
