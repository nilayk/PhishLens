Permissions

Every permission in the manifest, and why it is there.

Permission Why
host_permissions: https://mail.google.com/* Read the open message from the page in order to analyse it. This is the only site PhishLens can run on.
storage Persist the settings on this page. No message content is ever stored.
optional_host_permissions Not granted at install. If you configure your own model server, Connect asks for access to that one address, and only that one. Clearing the field gives it back.

Not requested: activeTab, <all_urls>, scripting, webRequest, tabs, or downloads.

Privacy

Message content is read into memory, analysed, and discarded. Bodies are never written to storage or logged in a release build. Results are cached in the tab only for as long as the tab is open. With AI off or on-device, nothing derived from a message leaves the browser. With your own model server, the display name, subject, and body excerpt go to the address you set above and nowhere else — no link targets, no recipient address, no attachments, and no API key.
